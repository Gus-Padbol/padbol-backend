# Demo interno protegido - Torneo #32 / Partido #63

Este demo se conserva temporalmente para mostrar al equipo el flujo cerrado y probado de torneo/partido.

## No tocar

Hasta nueva orden, no modificar:

- Torneo #32
- Partido #63

## Uso permitido

Solo usarlo para mostrar:

- carga manual de resultado;
- vista final del partido;
- ganador;
- parciales;
- resumen;
- fecha con año;
- experiencia visual Signature;
- modales Signature.

## Acciones prohibidas

No borrar el torneo.
No editar nombre, estado ni fechas.
No regenerar partidos.
No re-finalizar.
No resetear marcador.
No modificar resultado.
No usarlo para pruebas destructivas.

## Limpieza futura

Este demo se limpiará más adelante, cuando existan torneos de prueba reales con marcador completo.

## Nota

El demo vive en datos de producción. No hay hardcode nativo asociado al Torneo #32 ni al Partido #63.
